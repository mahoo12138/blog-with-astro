> 本文提出一套以权能解耦与契约选择为核心的“层级伴侣制度”（Layered Partner System），旨在以模块化、多层级的法定民事框架，替代现行高度均质化、全量捆绑的单一婚姻模型。

---

## 一、 引言：被困在单体架构中的现代亲密关系

审视中国现行的法定婚姻制度，其底层逻辑几乎完整继承自前工业时代的同质化社会结构：**异性结合、生育本位、终身存续、财务混同、人身连带**。这五个维度被深嵌进一枚不可分割的“原子化”胶囊之中。在法律的技术语境里，婚姻不是一份可以协商配置的协议，而是一道二元开关——要么是毫无民事关联的陌生人（0），要么承受全面无限连带的法定配偶（1）。

然而，当代社会的亲密关系光谱早已被撕裂为复杂多维的现实：

* **非婚同居者的法律悬崖**：数以千万计在超大城市共同生活的伴侣，维系着事实上的长期家庭生活，但在危重手术知情同意书前、在联名承租房屋的合约上，却被判定为“无权代表的法律路人”；
* **抚育与财产的恶性交织**：离婚诉讼往往陷入长达数年的财产拉锯与探望权争夺，子女被不自觉地工具化为博弈筹码，家庭解体最终演变为全员身心耗竭的零和博弈；
* **非传统形态的制度性真空**：丁克群体、同性伴侣、老龄丧偶后的互助生活共同体，在现行框架下要么被完全排斥，要么必须以极高的自设契约成本（如复杂的意定监护公证）来勉强搭建抵御风险的防护网；
* **家庭劳动的价值湮灭**：全职配偶在婚姻存续期间提供的长周期隐性抚育与家务照料，在司法裁判中往往只能折算为杯水车薪的“经济补偿”，其职业机会成本几乎得不到系统性确认；
* **代际财产纠纷的广泛蔓延**：“首付究竟算借款还是赠与”、“彩礼的清算边界在哪里”，原生家庭的财富焦虑与年轻一代的独立诉求剧烈对撞，直接推高了缔结婚姻的前置交易成本。

青年一代对婚姻的迟疑与后退，往往被舆论简单归咎于“利己主义”或“浪漫消亡”。但这是一种严重的认知怠惰。**人们真正恐惧的，从来不是亲密关系本身，而是一座缺乏缓冲带、进门即交出全部身家、出门必须剥落一层皮的“制度铁笼”。**

如果将现代公共制度视为一套社会运转的基础协议，那么现行婚姻法就像是一套庞大、僵死且不可拆解的**单体架构（Monolithic Architecture）**。任何维度的局部需求（哪怕只是危急时的一声医疗授权），都必须以挂载整套无限连带责任为代价。

破解困境的唯一技术路径是：**解耦（Unbundling）与分层（Layering）**。

将婚姻还原为一项国家提供标准默认契约、当事人保有选择自由的现代民事结合体系。国家不再垄断对“什么是正当家庭”的道德定义，转而履行其本职职责——**降低交易成本，保护真实付出，托底弱者尊严，并在破裂发生时提供秩序与体面。**

## 二、 系统设计的四项第一性原则

在重构伴侣制度之前，必须先确立制度设计的底线哲学。任何可持续的制度体系，都必须经受住极端人性的推演，而非寄托于道德圣人的自律。

### 1. 权能解耦与正交性（Orthogonality）
亲密关系包含三个截然不同、应当彼此独立的权能领域：
* **人身代表权**：医疗知情决定、涉诉代理、人道主义探视；
* **财产治理权**：生活成本分摊、新增财富归属、既有财产隔离；
* **抚育连带权**：后代的生活保障、监护义务与教育发展。

这三者在物理上与伦理上均不具备必然的绑定关系。一对丁克伴侣不需要抚育连带条款，一对合租搭伙养老的老人不需要财产混同。制度必须允许权利像模块一样被插拔。

### 2. 默认路径的仁慈性（Compassionate Defaults）
行为经济学早已证明：绝大多数人不会细读长达数十页的合同文本，陷入热恋的年轻人更羞于在立约时谈论清算。一个强制人人精算细节的“全量自选系统”在现实中注定失败。
**制度必须提供一套最符合现代都市理性认知的“全社会默认模板”（Default Architecture）。** 普通人什么都不用选，直接套用的就是这套阻力最小、保护最均衡的路径；只有具备特殊意图的人群，才需要主动去调整参数。

### 3. 退出的体面与止损效率（Procedural Dignity on Exit）
一项公共制度的道德成色，不体现在人们相爱时它如何锦上添花，而体现在感情消亡、彼此怨怼时，它能否阻断利用司法拖延进行的恶意消耗。
现行离婚程序中动辄一至两年的“判不离”冷冻期，在实践中往往沦为强势方转移资产、弱势方精神崩溃的温床。新制度必须确立**清晰的程序终局时间表**与**行政化快速解离通道**，将解除关系还原为民事清算，剥离道德审判，让退场保留起码的人道体面。

### 4. 制度中立与人道托底（Institutional Neutrality）
法律无权将公民划分为“符合主流道德”与“边缘不洁”的等级。无论是异性相濡以沫、同性相伴终生，还是无性共同体、晚年搭伙互助，只要存在长期、真实的共同生活事实，法律就必须为其提供基础的身份认许与防御权能。法律的使命是防范苦难，而非丈量偏好。

## 三、 三层制度架构总览

层级伴侣体系将民事伴侣关系划分为三个梯级，分别承载不同深度的承诺、责任与制度保护：

```
承诺与连带深度
      ↑
      │   ┌─────────────────────────────────────────────────────────┐
      │   │ A 类：深度融合共同体（Deep Community）                   │
      │   │ • A1 抚育型家庭合约：子女利益最大化 · 资产池治理 · 国家扶持 │
      │   │ • A2 终身伴侣合约：情感本位 · 性别中性 · 财产模式自选     │
      │   └─────────────────────────────────────────────────────────┘
      │
      │   ┌─────────────────────────────────────────────────────────┐
      │   │ B 类：生活共同体（Civil Coexistence） ★ 全社会默认路径    │
      │   │ • 资产双轨隔离 · 设立共同运营账户 · 家务劳动法定折算补偿   │
      │   │ • 动态抚育预设 · 独立儿童审查官 · 45 天无过错协议解离    │
      │   └─────────────────────────────────────────────────────────┘
      │
      │   ┌─────────────────────────────────────────────────────────┐
      │   │ C 类：登记伴侣关系（Registered Partnership）             │
      │   │ • 人身权利托底 · 紧急医疗代签 · 共同承租与信赖补偿       │
      │   │ • 零财产混同 · 填补事实同居与晚年互助的民事真空          │
      │   └─────────────────────────────────────────────────────────┘
      └─────────────────────────────────────────────────────────────→ 制度耦合度
```

| 维度 | C 类：登记伴侣关系 | B 类：生活共同体（默认） | A 类：深度融合共同体 |
| :--- | :--- | :--- | :--- |
| **核心定位** | 人道防线与功能性互助 | 现代独立个体的理性搭伙 | 命运同盟与高阶育儿实体 |
| **财产关系** | 绝对隔离，无任何法定共有 | 双轨制：个人财产隔离 + 共同生活账户 | 深度池化（A1）或定制化协议（A2） |
| **人身权利** | 紧急医疗签字、共同承租权 | 完整人身互代、医疗及监护权 | 完整人身互代与优先法定继承权 |
| **解除机制** | 简易通知解除（附信赖保护） | 协议解除 45 天 / 调解限时终局 | 强制咨询评定 + 严格抚育清算 |
| **国家支持** | 基础公共服务准入 | 标准家庭个税与信贷优惠 | 深度税收减免、住房优先、育儿配额 |

## 四、 C 类：登记伴侣关系（人道底线与真空填补）

### 1. 现实痛点：谁在法律边缘挣扎
在当下的医院手术室外，常常上演着同一种荒诞而残忍的场景：同居七八年的伴侣突发急症，在门外焦急守候的人，却因为没有一纸“结婚证”，被院方拒绝签署知情同意书；医生不得不辗转联系数千公里外多年不相往来的原生家庭亲属。
类似的情形还发生在出租屋管理、涉诉陈述、甚至一方离世后的遗体认领中。C 类的设立，正是为了彻底消解这片巨大的**法律无权真空**。它不要求双方对彼此的财产和未来做出沉重誓约，它只解决一个问题：**“在最脆弱的时刻，我们能不能互相拉一把。”**

### 2. 赋予的基础法定权能
C 类登记由当事人双方在民政线上平台或基层民政窗口签署完成，赋予以下不可剥夺的法定地位：

* **紧急医疗代签权**：在当事人意识不清或无民事行为能力的紧急医疗状态下，登记伴侣享有第一优先顺序的知情同意与代签权。医疗机构必须无条件认可其地位，直系亲属不得仅以血缘为由推翻其意愿表达；
* **民事联名承租与准入权**：享有与传统配偶同等的公共租赁住房联名申请权、商业租赁合同联名签署权，银行与房东不得拒绝承认其登记效力；
* **基本涉诉陈述与人道探视权**：在人身自由受限、看守所拘押、重症监护室等场景下，享有等同于近亲属的人道探视与事实知情权；
* **清晰的财产免责线**：C 类在法定层面上**彻底阻断财产混同**。登记不产生共同债务连带责任，不赋予法定继承权，亦不产生彼此的法定扶养义务。

### 3. 信赖利益保护与防遗弃机制
低门槛并不意味着可以作为逃避责任的游戏场。在非正式同居中，最典型的隐性剥削往往是：**“享受长期的生活照顾与情感支撑，待对方衰老或付出沉没成本后，单方面突然抽身。”** 为此，C 类设立三道渐进式防御机制：

```
┌─────────────────────────────────────────────────────────────┐
│ 第一道：6 个月制度观察期                                    │
│ 登记后前 6 个月内不得单方即时解除。单方提请解除须留出 30 天    │
│ 书面缓冲期，防止将公共登记沦为轻率的“试住工具”。           │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ 第二道：显性信赖补偿规则                                    │
│ 一方因伴侣关系做出重大实质牺牲（如跨省搬迁放弃原有工作、共同 │
│ 出资购置大件生活固定资产），提出解除方须依约定或法定指导价   │
│ 承担过渡安置补偿，返还沉没出资。                             │
└──────────────────────────────┬──────────────────────────────┘
```

> **绝对安全阀（家暴即时豁免）**：
> 凡涉及家庭暴力、人身虐待或重大威胁的，上述所有保护期与补偿约束对受害方**完全归零**。受害方可单方即刻撤回登记，系统联动签发 24 小时人身安全保护令并对接紧急庇护资源。

## 五、 B 类：生活共同体关系（现代个体的理性默认层）

B 类是整套制度设计的核心基石。它瞄准的是受过现代教育、拥有独立经济人格、既渴望真诚深刻的陪伴、又深知无限经济捆绑之危险的当代普通人。它的口号是：

> **“我们真诚地共同构建生活，但我们始终是彼此独立的自由人。”**

```
                  ┌─────────────────────────────────────┐
                  │      B 类生活共同体：三支柱架构      │
                  └──────────────────┬──────────────────┘
         ┌───────────────────────────┼───────────────────────────┐
         ▼                           ▼                           ▼
┌──────────────────┐        ┌──────────────────┐        ┌──────────────────┐
│   支柱一：财务   │        │   支柱二：抚育   │        │   支柱三：伦理   │
│                  │        │                  │        │                  │
│  资产双轨隔离    │        │  动态抚育协议    │        │  有限扶养义务    │
│  家庭共同运营池  │        │  独立儿童审查官  │        │  家务劳动法定确权│
│  清算原路按比返还│        │  90 天终局裁决   │        │  5 年周期审视    │
└──────────────────┘        └──────────────────┘        └──────────────────┘
```

### 1. 核心支柱一：双轨财产制与家庭公共运营账户
传统婚姻财产制度最大的弊端，在于把所有个人收入强制推入“共同共有”的大染缸，导致夫妻双方在日常消费中互相猜忌、隐藏私房钱。B 类彻底确立**财产双轨制**：

* **隔离层（个人特有资产）**：双方登记前的既有财产、存续期间各自名下的投资收益、知识产权所得、继承或受赠资产，在法律上保持绝对独立，任何一方不得越权主张；
* **运营层（家庭共同运营账户）**：双方设立一个联名日常运营资金池，用于承担房租、房贷、日用开销、宠物喂养与共同旅行。
  * **注入规则**：并不采取生硬均摊，而是依据双方**净可支配现金流的约定比例（默认推荐值为各方收入的 35%~40%）** 按月注入；
  * **底线保障**：设立法定最低注入红线（不低于当地最低工资的 50%），杜绝“名义共同生活、实际一方白嫖”的经济空心化；
  * **日常自主支配**：除划入共同账户的部分外，其余收入属于个人保留金，双方享有完全自由的支配权与知情豁免权，买喜欢的手办或护肤品无需向任何人报备；
  * **解离清算**：共同生活解体时，公共账户中的结余资金不按 50:50 一刀切切分，而是**按双方历史实际注资金额的真实权重原路返还**。

### 2. 核心支柱二：动态抚育预设与终局防拖延机制
在育儿问题上，B 类树立了一条至高无上的法理原则：**孩子的福祉独立于父母的关系，子女不是谈判筹码。**

若 B 类伴侣选择养育子女，系统自动挂载《标准化子女抚育附约》：
* **动态调整阈值**：抚养费与探望安排不是一锤定音的死契，当一方收入变动超过 30%、子女进入升学新阶段、或一方发生跨地域迁移时，自动触发调解复审；
* **防诉讼武器化的终局程序**：传统家事案件中，强势方常利用反复上诉、故意拖延将案件拖入两三年，以此在心理和财力上拖垮弱势方。B 类引入**限时终局裁决**：
  * 解离进入调解后，60 天内若无法达成一致，由民政派驻的**独立儿童权益审查官**出具中立安置建议书；
  * 建议书送达法院后 30 天内，法官必须据此做出最终裁决，除非有确凿证据证明该建议严重损害儿童利益；
  * **全程上限锁死在 90 天**，彻底封死借程序恶意拖延的空间。

### 3. 核心支柱三：家务劳动确权与有限扶养
“谁做饭带娃谁吃亏”是现代人不敢进入深入关系的根本痛点之一。B 类从制度层面将家庭再生产劳动确认为一项**法定资产贡献**：

* **全职补偿的法定触发**：若一方因承担育儿、照料老人等共同家庭事务，中断自身职业全职居家超过 12 个月，在关系解离时**自动触发家务劳动对价折算机制**。该权利具有强制性，双方不得在契约中事先约定放弃；
* **有限扶养义务**：若一方遭遇重大伤残或突发疾病丧失生活自理能力，另一方负有法定限期扶养责任，但该责任设定明确的**期限上限（不超过关系存续期的三分之一）** 与**额度上限（不超过扶养方收入的 30%）**，既保有人道温情，又防止将不幸无限期转嫁给另一方，形成不可承受的人生锁死。

### 4. 周期审视与温和解离通道
B 类契约默认设立 **5 年存续周期**。期满前 6 个月，系统向双方推送关系审视提示，双方可选择：
1. **平级续约**：续签 5 年，并借此机会复盘共同预算与条款；
2. **升级 A 类**：双方决定进入更深层的家庭融合；
3. **降级 C 类**：感情转淡但仍需功能性陪伴的软着陆过渡；
4. **协议清算**：启动解离程序。

在解离通道的设计上，无子女的 B 类解离仅需双方线上确认，经过 **45 天民事清算期** 后自动生效，无需出庭对薄公堂；单方提请解离则直接导入专业家事非对抗性仲裁，以财产清晰、精神止损为第一要务。

## 六、 A 类：深度融合共同体（生命托付与全能同盟）

如果说 B 类是理性人的清晰合作，那么 A 类则是**命运共同体的全能托付**。它代表了传统婚姻中最崇高的那部分愿景：全方位的资源融合、甘苦与共的人生重组。

### 1. A1：抚育型家庭合约（以孩子为圆心的防御要塞）
* **承接人群**：明确以繁衍后代为共同追求、自愿将私人生活深度整合、希望获得国家系统性生育福利倾斜的伴侣；
* **核心原则**：**儿童最佳利益原则高于一切成人的短期意志。**
* **资产池与受控释放机制**：
  * **深度池化**：主要收入（默认 70% 以上）汇入家庭核心资产池，用于购置不动产与长远育儿教育储备；
  * **尊严保留金**：为全职育儿方强制设定不低于法定比例的独立保留津贴，归其个人全权支配，彻底解决全职太太/丈夫“伸手要钱、丧失财务尊严”的结构性悲剧；
  * **资产异动防御**：建立防恶意资产转移机制。一旦系统侦测到单方提起解离、或双方出现长期分居等异常信号，资产池立即进入受限状态，非经双方签名或法官许可，大额资产处置自动冻结，斩断“离婚前夕转移资产”的劣迹空间；
* **国家政策全力倾斜**：A1 登记直接与国家最高规格的生育红利挂钩，包括梯度个人所得税大幅减免、公租房优先配租、父母双方强制性同等带薪育儿假，以及义务教育阶段的家庭综合保障。

### 2. A2：终身伴侣合约（情感本位的无边界托付）
* **承接人群**：坚定的丁克族、同性伴侣、步入晚年的搭伙老人、以及一切珍视精神共鸣而无意养育后代的成年人；
* **立法哲学**：**亲密关系的崇高价值，绝不依赖生育功能来证明。** 两个人决定在茫茫宇宙中结为彼此余生的唯一见证者与照料者，这一抉择本身就值得法律授予最高等级的庇护与敬意；
* **中性立法与定制财产**：
  * 法律文本彻底剔除性别指向，全程使用“伴侣甲方/乙方”，完全接纳同性民事结合；
  * 提供“完全共有”、“分类共有”或“自定义公证”三种财产模式，适配不同职业阶段伴侣的资产结构；
* **老年 A2 专项条款（阻隔代际继承纷争）**：
  * 许多老年人晚年丧偶后想找个伴，却遭到亲生子女的激烈反对，其根源往往是子女对房产继承权旁落的恐惧。
  * 老年 A2 设立**法定居住权（Usufruct）与产权所有权的精准剥离**：老人再结合并不改变原有不动产的权属，伴侣在世期间享有不可侵犯的合法居住权，而在世方离世后房产仍按原协议回流各自子女。这一规定用清晰的法律边界，化解了代际亲情与老年黄昏恋的残酷张力。

## 七、 制度防御层：直面人性的灰度与博弈

制度设计者最容易犯的错误，就是假定立约双方都是温良恭俭让的理性君子。事实上，亲密关系往往是人性最幽暗、最情绪化、最不对等的试炼场。制度必须自带防御机制。

```
┌────────────────────────────────────────────────────────────────────────┐
│                        制度运行的三大现实防线                          │
├───────────────────┬────────────────────┬───────────────────────────────┤
│ 1. 默认选择反诱导 │ 2. 代际资金标签化  │ 3. 原生家庭干预无效化         │
│ • 双设备独立签署  │ • 登记时强制归类   │ • 确立私法自治绝对边界        │
│ • 强制揭示关键差  │ • 未申报推定为赠与 │ • 24 小时紧急人身与居住保护令 │
│ • 杜绝“代点默认”│ • 阻断事后模糊撕扯 │ • 剥夺亲属的财产越权请求权    │
└───────────────────┴────────────────────┴───────────────────────────────┘
```

### 1. 默认路径的“反误导确认机制”
**现实风险**：在权力不对等的亲密关系中，强势一方容易用甜言蜜语或信息差忽悠弱势一方：“我们选默认项就行，不用管那么细”，形成实质上的不公契约。
**防御设计**：
系统在确认选择前，强制要求双方在各自独立的终端设备上，完成间隔不少于 24 小时的**独立知情同意确认**。界面必须醒目单列三项核心权利差异：
* *“您的伴侣在婚前购置的房产将与您毫无关联，您是否明确知晓？”*
* *“关系存续期间您各自名下的投资收益保持独立，您是否明确知晓？”*
* *“一旦协议期满，任何一方均有权拒绝续约且无需法定过错，您是否明确知晓？”*

两道独立数字确认的时间戳将永久留存，未来任何一方以“我当时不知道有这个条款”为由抗辩，均无法得到法庭支持。

### 2. 代际资金的“标签化穿透登记”
在中国家事审判中，“这笔买房钱是我爸妈出的，凭什么分她一半”是引发矛盾最激烈、证据最混乱的争议点。
**防御设计**：
在伴侣登记及存续期间，凡接受单方父母单笔超过本地年均可支配收入 50% 的大额资金注入时，系统**强制要求完成三选一的属性标注**：
* **标签 A（特有财产赠与）**：明确归出资方子女单方所有，即使购房也仅折算其个人出资比例；
* **标签 B（共同体投资）**：明确赠与小家庭共同体，转化为共同财产；
* **标签 C（家庭借款）**：附带正式借款协议，小家庭按约定按期偿还本息。

**逾期未声明的兜底推定**：凡未经明确标注的代际资金，法律一律推定为“对出资方子女个人的单方赠与”。通过这条冷酷但极具确定性的规则，迫使家庭成员在出资前把话说在明处，彻底根治事后算账的撕扯。

### 3. 原生家庭干预的“司法无效化”
传统家庭干预往往通过宗族式的人情绑架或经济制裁（“你若不把工资卡上交你妈，我们就闹到你单位”）。试图通过法律去改造家长的道德观念是徒劳的，制度设计的精髓在于：**让干预在法理上彻底失去效力。**

* **财产绝对阻断**：任何一方将个人保留金或共同体资金以无偿方式违规输送给原生家庭的行为，均构成对伴侣契约的根本违约，在解离时必须全额计入资产侵占并予以扣回；
* **居住空间排他保护**：伴侣依法共同居住的处所享有宪法级的人格尊严庇护。即便该居所的产权登记在一方父母名下，只要伴侣关系依法备案，父母强行换锁、闯入、骚扰的行为即构成非法侵入住宅，公安机关必须在 24 小时内出具隔离令。

## 九、 渐进式实施路线：权利插件（Rights Plug-in）策略

任何试图“明天就废除婚姻法、颁布层级伴侣法”的设想，在现实政治与社会惯性面前都是幼稚的乌托邦。过于激进的系统重构会立刻遭遇社会保守力量的全面防御，最终沦为空想。

最具有工程可行性的推进策略，是像操作系统更新驱动一样，采用**微内核与权利插件（Rights Plug-in）的渐进架构**：

```
第一阶段：权利插件（1-3年）          第二阶段：框架试点（3-5年）          第三阶段：法典编纂（5-8年）
┌───────────────────────┐          ┌───────────────────────┐          ┌───────────────────────┐
│ • 紧急医疗意定代理法  │          │ • 一线城市 B 类制度试点 │          │ • 《国家民事伴侣关系法》│
│ • 事实同居租赁权益确权│ ───────► │ • 设立专职儿童权益审查官│ ───────► │ • 替代现行单一婚姻法  │
│ • 性别中性 C 类伴侣登记│          │ • 司法自动化执行网络打通│          │ • 多元亲密形态全面法定│
└───────────────────────┘          └───────────────────────┘          └───────────────────────┘
```

### 1. 第一阶段（近期 1-3 年）：独立推行高共识度的“权利插件”
* **插件一（人道医疗授权卡）**：允许任意两名具备完全民事行为能力的成年人，无需证明亲属关系，直接通过民政App互换紧急医疗决定权。这不涉及财产、不涉及婚姻道德，阻力近乎于零，却能立刻拯救数十万在重症室外束手无策的同居与边缘群体；
* **插件二（租住与民事联名权）**：修改房屋租赁与民事代理规定，承认长期共同生活者享有共同签约、申领补贴的同等资格；
* **插件三（极简 C 类试点）**：在部分经济发达省份先行开放无财产混同的民事伴侣备案。

### 2. 第二阶段（中期 3-5 年）：B 类生活共同体的地方综合试验
* 依托特大城市高新技术园区、青年聚集社区，试点推广以“公共运营账户 + 动态抚育”为核心的 B 类协议模式；
* 组建由心理咨询师、财务审计师、法律援助律师构成的专业家事调解员网络，设立专职的儿童权益审查官职位；
* 打通民政、金融与司法执行机构的数据通路，完善小额抚养费与补偿款的自动扣缴机制。

### 3. 第三阶段（远期 5-8 年）：出台统一的《伴侣关系法》，实现法典级演进
在广泛试点积累充分司法判例与社会共识后，推动修改《民法典》婚姻家庭编，将单一的婚姻身份扩张为**C、B、A 三阶伴侣法定体系**，实现我国亲密关系民事制度从古典形态向现代治理文明的决定性跨越。

## 十、 结语：在人性的黎明与黄昏中，守住体面

人类为什么需要法律？

古希腊神话中有一张残忍的铁床，名叫普洛克路斯忒斯之床（Procrustean bed）。强盗将每一个过路人绑上铁床，身材矮小的就硬生生拉长，身材高大的就残忍地截断四肢，只为了让所有人都严丝合缝地吻合那张床的尺寸。

过去的婚姻制度，在很大程度上就像是这张床。它预设了一个标准化、无瑕疵的理想伴侣模型，然后强迫每一个走进现实生活的人去削足适履。当人们因为疼痛而挣扎时，舆论却在指责他们的骨骼长得不够规整。

**层级伴侣制度的终极追求，不是消解家庭，而是拆除这张铁床。**

它深知人性的软弱、疲倦、自私与不可预测，所以它用清晰的账目、独立的知情权、弹性的出口，为每一个人守住退路；
它同样坚信人类对爱、陪伴、抚育与相互照料的本能渴望，所以它赋予那些不愿被传统捆绑的灵魂，一份在阳光下挺起胸膛相伴而行的尊严。

当财产不再需要靠道德互相绑架，当告别不再意味着身败名裂的互戕，人与人之间的真诚、诺言与爱意，才终于能够脱离算计的泥淖，在真正自由的土壤中，安静而尊严地绽放。
