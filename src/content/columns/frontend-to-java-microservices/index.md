写给有 Web 前端经验、准备转向 Java 微服务开发与维护的读者。不需要 Java / Spring 基础，但需要会读 JavaScript、用过浏览器调试工具，理解 HTTP、登录态和数据库的基本概念。

这套笔记源于我深入学习和拆解一套真实企业级微服务生产项目后的技术复盘。项目技术栈涵盖 Spring Boot 3、Spring Cloud、Nacos、Dubbo、MyBatis-Plus、Sa-Token 和 Redis，以 `gateway-service`（网关）、`auth-service`（认证）、`system-service`（系统底座）、`equipment-service`（设备服务）等核心服务为背景。文中的包名、类名、表名、服务名和配置均已做通用化脱敏处理，核心聚焦于**架构语义、代码实现细节与排查方法**。

---

## 这套笔记解决什么问题

- 看懂一个 Spring Cloud 微服务项目从启动到处理请求的完整链路；
- 搞清楚微服务内部代码为什么这样组织，打破对 IoC、AOP、RPC、动态 SQL 改写的黑盒感；
- 能独立完成业务层「加字段、加查询、加接口、权限控制」等日常需求；
- 遇到 401/403/404、Dubbo 超时、慢 SQL、配置不生效时，能建立像排查前端 Network 面板一样的分层定位能力；
- 摸清多模块依赖与自动装配影响面，能安全地提交、上线与回滚；
- 遇到跨服务协作或线上故障时，能用扎实的日志与数据证据推进问题，拒绝空口报障。

---

## 怎么读

- **结合真实代码案例思考**：文中的代码片段均提炼自真实企业微服务的典型实现，重点观察注解使用、类与接口设计、参数流转与配置项。
- **每篇末尾配有自检题与练习**：建议先结合前端直觉思考解答，再对照答案验证，效果最好。
- **关于环境与配置**：各服务的端口、Nacos 命名空间、线程池大小、缓存 TTL 等运行时参数，以实际工程和环境配置为准。
